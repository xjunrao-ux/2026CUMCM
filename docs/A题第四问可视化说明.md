# A 题第四问移动边界可视化说明

## 目的

用同一组第四问有限体积结果同时展示：药材半径收缩、温度随时间和物理距离的变化、水分随时间和物理距离的变化。绘图不重新求解模型，不改变或平滑正式结果。

## 运行

在项目根目录依次执行：

```powershell
python code/a4_shrinkage_fvm.py
python code/a4_visualization.py
```

第一条命令将完整场结果保存到 `result/A_q4_shrinkage/`，第二条命令生成以下 PNG：

- `picture/A_q4_shrinkage/A_q4_moving_boundary_heatmaps.png`：温度和水分移动边界热力图；
- `picture/A_q4_shrinkage/A_q4_radial_profiles.png`：代表时刻的温度和水分径向剖面；
- `picture/A_q4_shrinkage/A_q4_center_surface_time_series.png`：中心与移动表面的温度、水分时间曲线。

绘图指标保存于 `result/A_q4_shrinkage/A_q4_visualization_metrics.json`。

## 图形口径

- 横向距离均为从药材中心量起的当前物理距离，单位 cm。
- 热力图黑色边界为当前表面 `R(t)`；斜线灰色区域在当前半径之外，属于已收缩域外，不是缺测值。
- 水分热力图采用对数色标，以兼顾 2.55 kg/kg 初值和接近 0.05 kg/kg 的低值区；红线为 `C=0.15 kg/kg` 干燥阈值。
- 径向剖面中的灰色虚线连接各时刻的移动表面端点，即 `(R(t), T_s(t))` 或 `(R(t), C_s(t))`，仅用于提示收缩边界随状态量的演化。
- 中心—移动表面时间曲线之间的浅蓝填充分别表示温度差和水分差。
- 正式场数据以 60 s、0.1 cm 保存。热力图仅在每个时刻的有效固定距离节点与精确移动表面值之间作分段线性插值，域外始终保持掩膜。

## 已验证结果

- 干燥结束时间：51.117222 h；
- 半径：2.000 cm 收缩至 1.200 cm，线收缩率 40.0%，截面积减少 64.0%；
- 记录中域外有效值、域内缺失值、径向水分次序违例和时间单调性违例均为 0；
- 粗细网格的干燥时间差为 4 s，第四问高精度结果通过网格对照与离散水分守恒检查。
