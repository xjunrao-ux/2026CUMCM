# A 题四问黑白物理流程图说明（v2）

## 1. 设计目标

本版流程图采用白底、黑框、黑箭头和无彩色填充的统一样式，将物理模型置于主视觉层，将有限体积、Picard 迭代和 Thomas 求解等数值步骤压缩为支撑层。四张图均按“物理对象与边界—控制方程—问题特有机制—数值实现—结果解释”的顺序组织。

## 2. 四问图示结论

| 问题 | 图示核心结论 | 主要评审风险处理 |
|---|---|---|
| 问题一 | 固定物性下，热传导和水分扩散共享几何与环境但没有直接反馈；两个 Biot 数均大于 0.1，内部热阻与质阻不可忽略 | 明确称为“同步传递”，不称强耦合 |
| 问题二 | 水分通过密度、比热和导热系数影响温度，温度与水分共同影响扩散率，构成双向物性耦合闭环 | 明确未加入蒸发潜热，并强调 Arrhenius 温度使用 K |
| 问题三 | 固定半径模型延拓长期边界，并以全域最大水分首次严格低于 0.15 作为终止事件 | 明确使用未舍入的全域值，不用表面值或平均值代替 |
| 问题四 | 材料坐标将移动区域映射到固定区间，半径通过控制方程中的 `1/R²(t)` 和表面边界中的 `1/R(t)` 进入模型 | 明确 11.11% 是收缩几何与附录 4 物性共同变化的综合结果 |
